# À propos du blog

Ce blog aborde différents sujets qui me passionnent, notamment :

- Le jeu Star Citizen
- Le développement de jeux vidéo
- Le féminisme
- La société
- Le bien-être
- L'intelligence artificielle (IA)
- Et d'autres thématiques variées

Le site a été conçu avec [Astro](https://astro.build/) et utilise le template de blog Yukina pour offrir une expérience moderne et élégante.
